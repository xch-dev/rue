# Rue

## README

Keep `README.md` short: what Rue is, installation, a quick start, the commands, the examples, the repository layout and how to contribute. The docs (https://rue-lang.com, in xch-dev/rue-docs) are the source of truth for language features, the standard library, lints, CLI flags, `Rue.toml` options and the language server, and they're updated from each release's PRs.

So a change that adds or changes a feature doesn't touch the README. Put the user-facing rules, with examples, in the PR description instead, which the docs update reads. Only edit the README when one of its own sections goes out of date, such as a new command, crate or contributor workflow.
